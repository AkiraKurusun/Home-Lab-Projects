The purpose of this project was to install the basic software I will need.

I installed the following:

* Pika Backup: Used to create backups of my hard drive so I can revert back to them if needed in the future.
* ZSH & Oh-my-zsh: For terminal customization. I choose to install Powerlevel10k as my theme.
* Google Authenticator for 2FA with SSH and Local Computer Login
* FZF for easier file viewing
* EZA for better directory and file configuration viewings
* Bat for a better viewing of files instead of Cat



Notes:
* Configured GitHub Remote Repository with SSH keys so I can push from my Kali Machine. Also ensured that SSH Sessions also had access and were required to authenticate.
